# ⚡ Energy Consumption Dashboard (SQL + Excel)

## 📌 Project Overview
This project analyzes energy consumption data (Water, Electricity, Gas) using SQL and Excel.  
The goal is to identify consumption patterns, cost trends, and building-level insights.

---

## 🛠️ Tools & Technologies
- SQL (Data Cleaning & Queries)
- Microsoft Excel (Power Pivot, Pivot Tables, Dashboard)
- Data Visualization

---

## 📊 Key Features
- KPI Metrics:
  - Total Consumption
  - Money Paid
  - Consumption Ratio
- Time-based analysis (monthly & yearly trends)
- Building-wise comparison
- State-wise consumption visualization (map)

---

## 🧠 What I Did
- Explored and analyzed energy dataset using SQL queries  
- Understood data relationships between buildings, rates, and consumption  
- Worked with Excel dashboards and interactive filters  
- Generated insights from consumption trends
